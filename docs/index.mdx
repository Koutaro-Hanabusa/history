### 社内向け・顧客向け管理画面の改善

期間: 2025 年 5 月 〜 2025 年 10 月
役割: メンバー / プロジェクト規模: 5〜10 人
使用技術: PHP / Go / TypeScript, Laravel / React
担当工程: 要件定義 / 仕様設計 / コーディング / レビュー

#### 業務内容

社内オペレーション向け・顧客向けの 2 系統の管理画面（React + Laravel / React + Go）の改善。フロントエンドを主軸に、FE/BE が連動する改修を幅広く担当。

#### 実績・取り組み

- 途中参加のため、既存ドキュメントの読解と PdM・先行メンバーへのヒアリングによる課題の再定義から着手
- 申し込みフローの画面リプレイス。社内オペレーションの工数削減と、顧客側の入力ミス削減を実現
- 編集機能の追加による、申し込みのやり直しコストの解消
- β 版デザインシステムの構築。後の全社デザインシステムの土台として採用

### 業務ツールの Web 化プロジェクト

期間: 2025 年 10 月 〜 2026 年 2 月
役割: メンバー / プロジェクト規模: 5〜10 人
使用技術: PHP / TypeScript, Laravel / React
担当工程: 要件定義 / 仕様設計 / コーディング / レビュー / テスト・QA

#### 業務内容

現場スタッフが大量の写真を検査・納品するデスクトップツールの Web 化。フロントエンドとして参加し、機能実装に加えて技術基盤の刷新まで担当。

#### 実績・取り組み

- 機能実装前の言語・テスト・Lint まわりの整備による技術的負債の解消（[プロダクトブログ掲載](https://productblog.sencorp.co.jp/entry/2025/12/15/100000)）
- 既存 UI ライブラリから Tailwind CSS への部分移行の提案・実施
- 写真バリデーションのスキーマベース（Zod）化。技術検証を経て、既存仕様を変えずに型安全と保守性を両立
- 業務ドメイン特有の例外パターンに対応したバリデーションルールの実装
- 社内向けの先行公開期間を設けた段階的リリースの設計

#### 成果

- 写真バリデーションの所要時間を 489,173ms → 4,134ms（約 100 分の 1）に短縮
- 納品フロー全体の大幅な高速化を実現し、下期の社内表彰（ベストチーム賞）を受賞

## 自己 PR

### フロントエンドを軸にした開発と新しい技術へのチャレンジ

React / TypeScript を主軸に、社内向けの業務システムから顧客向けの管理画面、社外スタッフ向けのツールまで、ユーザーが直接触れるプロダクトの設計・実装を担当してきました。必要に応じて Laravel / Go によるバックエンド改修にも踏み込み、API 設計や FE/BE 連携も対応できる点が強みです。

登場して間もない技術をプロダクト基盤に取り入れることにも積極的で、フロントエンドのみで 1 プロダクトを構築する PoC では技術選定を担当し、TanStack Router の採用を決定しました。事例が少ない中でもディレクトリ構成や運用方法を試行錯誤しながら整え、長期運用と開発体験の更新を両立できる形に落とし込むことを意識しています。

### デザインシステムの構築と展開

管理画面の改善プロジェクトで構築した β 版デザインシステムが、全社デザインシステムの土台として採用されました。現在は全社共通デザインシステムの新規構築にフロントエンドとして参加し、コンポーネントの設計・実装から、VRT、CI/CD、Figma Code Connect などの基盤整備まで幅広く担当しています。複数プロダクトに影響が及ぶ性質を踏まえ、「安心して変更できる土台」を先に整えることを重視しました。

また、「デザインシステムを作っても使われない」ということがないように、AI エージェントが常に最新の仕様を参照できる運用形態を模索しています。デザイナー向けにも AI エージェントとデザインシステムを組み合わせたプロトタイピング環境を整備するなど、AI 駆動開発時代における開発体験の更新に取り組んでいます。

### ユーザー体験向上への貢献

管理画面の改善やツールの Web 化では、単なる機能実装にとどまらず、エンドユーザーの使いやすさを重視した開発を行いました。その結果、社内オペレーションの効率化だけでなく、顧客や現場スタッフからも好評を得られています。
